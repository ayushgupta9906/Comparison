# Result Comparison
## Setup Instructions

To set up the project, follow these steps:

### Frontend

1. Navigate to the frontend directory:
    ```sh
    cd frontend
    ```
2. Install the dependencies:
    ```sh
    npm i
    ```
3. Start the development server:
    ```sh
    npm run dev
    ```

### Backend

1. Navigate to the backend directory:
    ```sh
    cd backend
    ```
2. Install the dependencies:
    ```sh
    npm i
    ```
3. Start the development server:
    ```sh
    npm run dev
    ```
